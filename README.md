# Bank Customer Churn Prediction

## Objective
Predict the likelihood of customer churn using Machine Learning.

## Dataset
Bank Customer Churn Dataset

## Preprocessing
- One-Hot Encoding
- MinMax Scaling

## Model
Logistic Regression

## Train-Test Split
80/20

## Metrics
- Precision
- Recall
- F1 Score
- ROC-AUC

## Output
churn_predictions.csv
